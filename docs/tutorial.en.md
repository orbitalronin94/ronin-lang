# RONIN 1.1 — Beginner tutorial (English companion)

This file is an English companion summary. The complete source tutorial, including all nine chapters and the koans, is maintained in [Spanish](tutorial.md).

The tutorial introduces RONIN as a declarative way to model finite systems competing for scarce resources. It walks through the concepts of agents, resource, capacity (phi), consistency (psi), frequency, alpha, gamma and sigma; then builds progressively more complex systems, introduces the CES-Saturated family, explains K–alpha degeneracy diagnostics, common validation errors and the command-line reference.

The nine-chapter sequence is: (1) What a system is; (2) Your first RONIN system; (3) Meaning of each parameter; (4) Progressive examples; (5) The CES-Saturated family; (6) Degeneracy diagnosis; (7) Common errors; (8) Quick reference; and (9) Tutorial koans.

The Python reference runtime currently executes only the documented system subset. Advanced constructs in the tutorial should be read as language specification or design material unless a matching implementation is explicitly documented.
