# RONIN 1.1 — Formal language specification (English companion)

This is an English overview, not a full translation. The complete formal specification (sections 0–14, including syntax, types, concurrency, interoperability, compilation, tooling, Linux integration and software-development applications) is in [Spanish](spec.md).

The specification frames RONIN around systems, agents, scarce resources, deterministic allocation and explicit validation. It describes system declarations, agents, parameter blocks, arrays, functions, control flow, modules and macros; primitive, domain, compound, parametric and experimental dependent types; actors, channels, futures, promises, streams and backpressure; interoperability with Python, Rust, SQL, REST, GraphQL, WebSockets, gRPC and common data formats; native/WASM/C/Python/LLVM/JVM/.NET/JavaScript compilation targets and interpreter tooling; complete use cases, diagnostics, Linux-native integrations and software-development applications.

Normative text, proposed capabilities and implemented runtime behavior are distinct. Consult the Spanish source and the repository coverage notes before treating a described capability as available.
