# RONIN Office specification — English companion

The complete Spanish source transcription is [`office-spec.md`](office-spec.md). It describes the visual design environment and its Chat, Sheet, Optimizer, Simulator, Agent Studio, and Diagnose panels, the JavaScript engine, workflows, local system generation, and technical references.

The current `office/index.html` is a local prototype. It includes deterministic help, CSV import/export, a heuristic alpha sweep, seeded simulation, agent creation, and diagnostics. It is not the full collaborative product: there is no LLM-backed chat, complete RONIN editor, project persistence, global optimizer, or temporal-memory system.
